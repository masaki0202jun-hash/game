# 昆虫とおしりの部屋

幼少期の虫取りから、約十年後の事件の調査へ続く、手描き調の探索・謎解きホラーRPGの完全版です。HPや戦闘はありません。専用タイトル画像と、日常・森・虫取り・調査・悲しみ・夜・恐怖・タイトルの8種類の場面別BGMを収録しています。

## 遊ぶ

公開版：https://masaki0202jun-hash.github.io/game/

タイトルで「はじめから」「つづきから」「十年後から」を選べます。「十年後から」は、本編の調査を直接確認するための入口です。

- 矢印キー / WASD：8方向移動
- Enter / Space：会話を進める・調べる・虫取り網を振る
- 本編では、調べたい対象をクリックしても移動・調査できます。
- アイテム欄：選択・拡大・使用
- 調査手帳：見つけた情報を読み返す
- 次の手がかり：次の調査先を確認する
- 保存：現在の進行をこのブラウザーへ保存
- タイトル：進行を保存してタイトルへ戻る
- 右下のBGM操作：消音と音量調整。設定はこのブラウザーへ保存します。

進行は自動でも保存します。会話中の保存は、その場面の冒頭や直前の調査から再開します。

## 開発

編集元は `src/painted-game.template.html`、幼少期後半は `src/after-forest.js`、本編は `src/adult-story.js`、保存機能は `src/game-progress.js` です。BGMは `src/bgm.js` に記譜したオリジナルの旋律と伴奏をWeb Audioで演奏します。場面に合わせてフェードで切り替わり、最後の墓では効果音を残してBGMを引きます。

画像は `assets/` に置きます。次のコマンドで画像を埋め込んだ単体HTMLを作ります。

```sh
python scripts/build-browser.py
```

`index.html` が公開版です。`gh-pages` ブランチへ反映するとGitHub Pagesが更新します。

ローカルで確認する場合はHTTPサーバーを使います。

```sh
python -m http.server 8000 --directory .
```

## 実装範囲

家での準備、村、森の探索、カブトムシ取り勝負、帰宅後と夜の事件、十年後の村の調査、アイテムを使う探索、複数のパスコード、終盤の宝箱、墓での余韻を残す結末まで、最後まで進められる完全版です。
